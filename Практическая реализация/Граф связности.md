
Представляет собой взвешенный граф, где вершины - понятия(люди/события, далее юниты), а рёбра - их связи.

# Цель и задачи

Хранит понятия/людей/воспоминания, представленные юнитами. Имеет область выделения, переносит в него объекты, найденные по переданном слову или набору слов. В последствии дополняется смежными юнитами. Это позволяет дополнять контекст, быстро находить смежные темы, людей и воспоминания. 
охранение идёт в формате json. Это позволяет хранить информацию при перезагрузке программы.
# Составляющие
## Юниты (понятия/люди/события)

Каждый узел помимо основного наименования имеет дополнительное поле для синонимичных определений, при поиске юнита они являются равноценны основному.
Каждый юнит содержит:

| Наименование поля     | Понятие                | Человек                       | Воспонинание                                               |
| --------------------- | ---------------------- | ----------------------------- | ---------------------------------------------------------- |
| `Тип`                 | Понятие                | Человек                       | Воспоминание                                               |
| `Основное поле`       | Основное понятие       | Имя человека                  | Краткое название воспоминания                              |
| `Второстепенное поле` | Синонимические понятия | Другие имена (ники, прозвища) | Дополнительные наименования для воспоминаний               |
| `Описание`            | Интерпретация понятия  | Краткое описание для него     | Описание и контекст воспоминания, достаточный для его цело |
| `Связи`               | ->                     | Связи с другими элементами    | <-                                                         |
## Рёбра
Выполняют роль связей между юнитами. Они одержат:
- `date_use` - время последнего взаимодействия.
- `weight` - вес ребра. Всегда больше 0.
# Процесс работы.

### Методы:
- `select_target` - получает на вход 1 слово и производит поиск юнита. Если он был найден, то добавляется в область выбранных.
- `select_clear` - очищает область выбранных понятий.
- `select_expansion` - дополняет область выбранного новыми  юнитами.
- `load_graph_from` - загрузка графа из адреса по указанному пути.
- `save_graph_to` - сохраняет граф в файл по указанному пути
- `create_unit` - создаёт юнит, принимает основное понятие и список второстепенных 
- `add_synonym` - добавляет синоним к существующему юниту.
- `add_unit` - добавляет уже созданный юнит.
- `add_edge` - Добавляет связь между юнитами, принимает понятия, как обозначение юнитов для связи.
- `get_unit` - находит юнит по основному или второстепенному полю.
### Расширение контекста (select_expansion)

**Терминология:**
- **Выделение** - нахождение в области выбранных.
- **Первичные юниты** - юниты которые были выделены до начала расширения.
- **Новые юниты I (II)** - юниты добавленные в процессе расширения в первую и вторую волну соответственно.

**Имеет два шага:**
- **Поиск гарантированных связей.**
  Если уже выделенные юниты имеют общие юниты, то последние будут выделены, как новые юниты I.
- **Случайный поиск.**
  1. Среди первичных юнитов отбираются те, кто имеет связи.
  2. Среди их связей выбираются случfйным образом n штук. Вероятность выбора распределяется согласно их весу.
  3. Юниты, к которым ведут связи будут выделены как новые юниты II.

При повторном запуске, все ранее выделенные новые юниты становятся первичными. Повторный запуск может позволить найти более глубокие связи в графе. Теоретически это может снизить его эффективность из-за слишком разных областей.
