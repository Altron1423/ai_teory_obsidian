Проверяет содержимое ответа, отправляет вызванные инструменты на исполнение. 
Оценивает историю диалога, ответ модели передаёт ответ конечному получателю (если это требуется), передаёт новые данные в блоки памяти.

## Правила парсинга 
Обычный текст, без вызова стандартных инструментов. Должен иметь дополнение в своей структуре:
```
{...}
[TOOL: {...}]
[Кому: {...}, Куда: {...}]
{...}
```
  **Пример заполнения**
```
Ваня проснулся и появился в сети.
[Кому: Ваня, Куда: личное]
Доброе утро! Как дела?
```
* Первыми идут внутренние мысли модели, они не будут отправлены, какому либо пользователю и останутся внутри модели для использования при формировании контекста и личного характера. Может быть как вместе с сообщением, так и единственным значением,  и отсутствовать вовсе.
* 
* Далее поля адресата (присутствует только в паре с текстом сообщения, может быть несколько):
  * `Кому` указывает получателя, который является целью ответа.
  * `Куда` указывает место: личка, группа или другой источник. Данный параметр не обязателен, при его отсутствии сообщение будет переслано в место получения.  
* Последним идёт текст сообщения в свободной форме. Должен существовать, если есть поле адресата.
Отсутствия вызова инструмента или разделителя с адресатом говорит о том, что весь текст - внутренние мысли.
Несколько полей адресатов => отправляется несколько сообщений, текст сообщения считывается от поля адресата до следующего поля адресата или конца ответа модели.
